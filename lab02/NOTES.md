Рабочая папка - это место, где ты редактируешь файлы.

Индекс - это список изменений, которые готовы к коммиту.

Коммит - это снимок состояния файлов.

Git - локальная система контроля версий.

GitHub - удалённый сервис для хранения репозиториев и своместной работы.

git status - показывает текущее состояние репозитория: какие файлы изменены, какие добавлены в индекс, есть ли неотслеживаемые файлы. Помогает понять, что готово к коммиту, а что ещё нет.

git diff - сравнивает рабочую папку с индексом. Показывает изменения, которые ты сделал, но ещё не добавил. Это черновик, который Git пока не видит как готовый к фиксации.

git diff --staged - сравнивает индекс с последним коммитом. Показывает именно то, что попадёт в следующий коммит после. Это и есть работа с индексом: ты видишь, что реально будет зафиксировано.
